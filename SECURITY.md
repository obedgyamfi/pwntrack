# Security Policy

## Supported Versions

| Version   | Supported          |
|-----------|--------------------|
| latest    | ✅                  |
| older     | ❌                  |

We support only the **latest release** for security patches.

---

## Reporting a Vulnerability

If you discover a security vulnerability, please:

1. **Do not** publicly disclose the issue.
2. Email **security@pwntrack.com** with:
   - A clear description of the vulnerability.
   - Steps to reproduce.
   - Potential impact.
   - Any suggested fixes.
3. Expect a response within **72 hours**.

---

## Scope

PwnTrack is intended for **lawful security research** and **bug bounty participation**.  
Testing outside of these legal boundaries is strictly prohibited.

---

## Handling Vulnerabilities

1. Confirm the report and reproduce the issue.
2. Prioritize severity (Critical, High, Medium, Low).
3. Develop and test a patch.
4. Release a security advisory with a fixed version.
